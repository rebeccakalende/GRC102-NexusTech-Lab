# 1. Introduction

NexusTech Solutions is a rapidly growing software company specialising in cloud-based Enterprise Resource Planning (ERP) solutions. The organisation has grown from approximately 50 to 250 employees and now serves high-profile financial and healthcare clients.

The company previously relied on a five-year-old "IT Rules" document that combined policy requirements, technical instructions and general recommendations. This created inconsistent practices, unclear accountability and potential compliance gaps.

As the Information Security Manager, the objective of this practical laboratory was to establish a more structured and maintainable security policy framework that supports the organisation's security and governance objectives.

This report presents the five evidence bundles developed during the laboratory:

- Security Policy Hierarchy
- Acceptable Use Policy
- User Access Request Procedure
- Communication and Training Plan
- Policy Review and Maintenance Memo

# 2. Task 1 – Security Policy Hierarchy

## 2.1 Policy Hierarchy Definitions

| Document | Purpose | Authority | Mandatory or Recommended | Level of Detail |
|---|---|---|---|---|
| Policy | Defines the organisation's overall security requirements and direction. | High | Mandatory | High-level |
| Standard | Defines specific requirements that must be met to support a policy. | High | Mandatory | More specific |
| Procedure | Provides step-by-step instructions for carrying out a requirement. | Operational | Mandatory where applicable | Detailed |
| Guideline | Provides recommended practices to help users meet security objectives. | Advisory | Recommended | General guidance |

## 2.2 Statement Categorisation

| # | Statement | Classification | Justification |
|---|---|---|---|
| 1 | All NexusTech employees must use MFA when accessing the corporate network remotely. | Policy | It establishes a mandatory security requirement for employees. |
| 2 | To configure MFA on a mobile device, download the Authenticator app, scan the QR code provided in the IT portal, and enter the six-digit verification code. | Procedure | It provides step-by-step instructions for configuring MFA. |
| 3 | It is recommended that developers use parameterised queries to reduce SQL injection risk. | Guideline | It recommends a security practice rather than making it mandatory. |
| 4 | NexusTech is committed to protecting the confidentiality, integrity and availability of all client data. | Policy | It states a high-level organisational security commitment. |
| 5 | All corporate laptops must have full-disk encryption enabled using BitLocker or FileVault. | Standard | It defines a specific mandatory technical requirement. |
| 6 | Employees should avoid connecting to public, unsecured Wi-Fi networks when travelling. | Guideline | It provides recommended behaviour rather than a mandatory requirement. |
| 7 | In the event of a suspected security breach, employees must immediately contact the IT Helpdesk at extension 5555. | Procedure | It tells employees what action to take when a specific event occurs. |
| 8 | Passwords must be a minimum of 14 characters and contain at least one uppercase letter, one lowercase letter, one number and one special character. | Standard | It defines specific mandatory password requirements. |
