# NexusTech Solutions Policy Review and Maintenance Memo

**To:** Information Security Steering Committee  
**From:** Information Security Manager  
**Date:** 18 September 2027  
**Subject:** Security Policy Review and Maintenance

## 1. Purpose

This memo recommends a review of NexusTech Solutions' security policies to ensure that they remain relevant, effective and aligned with the company's current technology environment and security risks.

## 2. Review Triggers

Two significant events have triggered the review:

1. **AWS Migration** – NexusTech's primary database has been migrated to AWS, creating changes in the technology environment and associated security risks.
2. **Security Incident** – An employee shared a sensitive document through personal cloud storage, highlighting the need to clarify acceptable use and information-sharing requirements.

## 3. Review Process

The policy review should include the following activities:

### 3.1 Stakeholder Consultation

Consult relevant stakeholders including:

- Information Security
- IT
- Management
- Human Resources
- System and data owners
- Relevant business users

Stakeholders should provide feedback on whether the current policies remain practical and effective.

### 3.2 Risk Analysis

Review the security risks associated with the AWS migration and the recent information-sharing incident.

The review should identify new or changed risks and determine whether existing controls adequately address them.

### 3.3 Evidence Review

Review relevant evidence such as:

- Security incidents
- Access request records
- Policy acknowledgements
- Training completion records
- Audit findings
- User feedback
- Security monitoring information

The evidence should be used to identify gaps and areas requiring improvement.

## 4. Recommended AUP Updates

Based on the review triggers, the Acceptable Use Policy should be updated in the following areas:

### Update 1: Personal Cloud Storage

Clarify that employees must not upload, store or share confidential company or client information using personal cloud storage services unless specifically authorised.

This directly addresses the recent incident involving the sharing of sensitive information through personal cloud storage.

### Update 2: Cloud Services and AWS

Add clearer requirements for the use of company-approved cloud services and systems.

Employees should use only authorised company cloud platforms for storing and sharing company information and must follow applicable security requirements.

### Update 3: Information Sharing

Clarify employees' responsibilities when sharing sensitive or confidential information, including verifying that recipients and sharing platforms are authorised.

## 5. Policy Ownership and Approval

The **Information Security Manager** remains responsible for maintaining and coordinating reviews of the security policies.

Significant policy changes should be reviewed by the relevant stakeholders and submitted through the appropriate management approval route, with final approval by the CEO where required.

## 6. Review Frequency

The security policies should undergo a formal review **at least annually**.

An early review should also be triggered by:

- Major technology or infrastructure changes.
- Significant security incidents.
- Changes in regulatory or compliance requirements.
- Significant changes in business operations.
- Identification of major security risks or control weaknesses.

## 7. Conclusion

The AWS migration and recent security incident demonstrate the importance of keeping NexusTech's security policies current.

The recommended updates will clarify acceptable use of cloud services, strengthen information-sharing requirements and ensure that policy controls continue to reflect the company's changing security environment.
